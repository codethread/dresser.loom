# dresser.spool

`skein.spools.dresser` bootstraps and maintains opinionated repo conventions
for [Skein](https://github.com/codethread/skein) as a git-distributed spool:
versioned, per-aspect convergence workflows that an agent drives against a
target repo, with mechanical `:shell`-gate verification and a checked-in
receipt of what was applied.

Dressing the loom is the weaving step of setting it up — warp, tension,
tie-up — before any cloth is woven. This spool does that for repos.

Contract documentation lives in [dresser.md](./dresser.md). Design history
for the initial feature lives under `devflow/feat/conventions-spool/`.
